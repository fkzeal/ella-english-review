# 多账号本地缓存

从 0.7.7 起，账号的完整备份、同步基线和冲突快照存放于 IndexedDB
`ella-account-cache` 的 `snapshots` 表。localStorage 继续存放当前练习、
账号绑定、设备安装编号和宝箱待确认操作，账号与云端协议不变。

启动时先迁移旧账号缓存，再更新共享题库；登录、同步及迁移前备份导出也会检查迁移。
所有旧缓存先在一个 IndexedDB 事务中保存，事务完成后才删除对应的 localStorage
副本。读取失败、数据库受阻或保存失败时保留原始副本，不能清空学习记录来释放空间。
删除前再次比较原始字节，避免删除其他页面刚写入的记录。若数据库中已有更新的快照，
保留新快照，将不同的旧副本另存为 `migration-` 记录，不覆盖较新的记录。

切换账号前保留当前账号备份，返回时读取该账号自己的缓存并与云端合并。
首次初始化另一个账号时仅使用共享题，不继承上一账号的私有题、作答或奖励。
既有账号题量保持；新账号默认每组 10 题。迁移前备份导出从 IndexedDB 异步读取，
离线时仍可导出。IndexedDB 不可用的环境保留原有 localStorage 路径，不擅自删除数据。

回归测试覆盖迁移失败保留、较新快照不被旧迁移覆盖、大快照持续写入和账号同步、
导入、奖励回执幂等。浏览器测试以本地 D1 隔离环境运行，预先填满旧缓存并升级题库，
随后在同一设备中对六个账号连续切换 18 次、刷新并核对进度与私有题归属。
这些测试不使用或修改生产账号。
