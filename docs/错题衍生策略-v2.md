# 错题衍生生成：覆盖优先、按需补足（2026-11-22）

本规则替代旧的“较新独立正确就排除”和“两个题号即足够”。不改变实时组题、默认题量、奖励、日期、历史或未完成组。实时十题一组与跨组覆盖由另一分支实施；本分支上线不代表该功能上线。

`practice.select` 是候选和发布端共同使用的纯判断函数。只接纳 Ella 已核验 live / imported 记录；帮助后答对也属于薄弱证据。按 `(targetKey, unitKey)` 判断，targetKey 包含 lessonId。共享旧 reviewUnit 的不同目标不互相抵消。未测本身不触发扩题。

同日改对不关闭需求。最新错误/帮助日期之后，不同有效题族首次独立通过可暂停扩题；只有原题时需要两个后续日期首次独立通过，标记单题证据，不声称迁移或掌握。缺时间顺序时，同题族当天含错误/帮助不能当首次独立通过。

至少两种经核验的同目标同能力题族先复用；多日错误/帮助且供给足够时标记待讲解。尚未做过的已发布变式先等待。只缺一种通常补一题；同目标跨能力每批合计最多两题、生成后七天冷却、每日六题。多个题号、换序、换名字不能证明不同题族。多题供给未完成题族核验时暂停扩题并标记待核验。

题族元数据保存在私有 D1 `account_practice_variant_catalog`，按评价指纹核对，字段为 questionId、fingerprint、targetKey、unitKey、variantFamily、status、note。`needs-material` 阻止围绕需核查原题生成。单一原题默认一个基准题族，多题须人工核验。POST 管理接口 `/api/admin/practice/variants` 只更新私有目录，账号版本与学习 state 不变；目录 revision 单独防并发。题目正文白名单和评价 identity 保持不变。

维护命令 `review-families PRIVATE_REVIEWED` 上传核验清单并回读。`publish-private` 的输入每题须有 variantFamily，程序剥离为包外 variantFamilies sidecar，同时传 expectedVariantRevision。发布端二次核对目录版本、实际供给缺口、目标限额及重复题族，在同一事务写题与目录。响应丢失必须沿用保存的精确 payload / runId；已存在旧回执仍先按精确哈希恢复，不要求旧包补字段。

`candidates` 将独立决策、来源类别、题族、基题指纹与原因保存到私有 operations。报告区分真实新增/启用主要目标和原目标变式（净新增主要目标零），继续展示本轮所有账号已授权公开的衍生题正文。U/C 仅统计账号已学且可练范围的有效唯一主要目标；错误/帮助可计初筛。新题号不重置初筛。R、稳定掌握与七日 I 缺必要逐目标窗口/目录历史时为未知；七日 C 是有效历史观察值，不代表无记录日期已验证零作答。不能据此承诺全部覆盖。

运行零候选是正常完成；失败读取不能记零。定时成功须独立 schedule 执行及完整生产回执；手动实施只可报告 manual-maintenance-complete。沿用原任务和原发布链路。
