# 温故 · 家庭英语复习小站（0.4.1）

学生端点「开始练习」，选择答案立即收到对错与解析。家长端查看题库、课程与学习批次、自动复习日程，并备份学习记录。配色沿用浅蓝、亮蓝、青绿与暖黄方案。

## 使用方式

1. 妈妈把当天学习材料发给爸爸。
2. 爸爸在 TRAE 对话中提供实际学习日期、RAZ 级别/书名或剑桥 Lesson、正文截图和实际词表。
3. 助手核对材料，在 `question-bank.json` 维护考点、原创客观题及 `batches`。
4. 通过测试、构建并上传同一个网站。妈妈打开原网址即可同步，无需导入或勾选课程。
5. 网页在浏览器中根据学习批次与答题表现动态选题，不调用模型。

目前 My week、Greater Than、Animal Tongues 共83道原创题，分别覆盖17、10、12个主要学习目标；历史上的每课5项是练习分组，不是知识点总数。Country Places 正文未取得，仍待建库。未提供实际日期时内部沿用模块生成日前一天，日期来源保留为 default；界面只调整首次学习日期。实际确认批次优先于默认日期，本地修改优先于发布批次。详见《复习策略与考点核查.md》。

## 本地运行及部署

云任务项目根目录已整理为 `/workspace`，该目录现在直接包含 `.git`、源码与 GitHub remote，供 TRAE 的“转至本地执行”检查。`/workspace/english-review` 是兼容旧链接的本地符号链接，未加入 Git。上传素材、历史 ZIP、独立预览 HTML 均未加入仓库。Git 仓库根目录迁移已验证；实际任务转移需在 TRAE 桌面端完成并核对。

需要 Node.js 18+，无需安装依赖。

```sh
npm test
npm run build
npm start
```

本地服务默认 `http://localhost:4173`，可用 `REVIEW_PORT` 调整端口。这是开发服务，不是长期公网地址。

构建生成 `dist/` 静态站点及 `/workspace/英语复习小站.html` 单文件。在线部署上传 **dist 内全部文件**，保留原域名/路径和 HTTPS；不要只上传单文件，否则独立题库无法更新。兼容一般静态托管及已有服务器。`_headers` 用于支持该文件的托管平台；其他平台参考 `nginx.conf` 禁用题库缓存。

已有 Docker 服务器可用：

```sh
docker build -t lesson-loop .
docker run -d --name lesson-loop -p 8080:80 lesson-loop
```

固定生产网址为 https://ella-english-review.pages.dev/ 。本地修改、构建成功不等于已发布；发布状态见 `HOSTING.md`。更新时部署新的 dist，域名不变。跨域名、协议、端口会形成不同浏览器存储，需要先备份。

固定托管已配置 Cloudflare Pages，操作与当前授权状态见 `HOSTING.md`。后续发布执行 `npm run deploy`，会自动测试、构建并更新同一生产项目。账号授权完成且部署验证成功前，不视为已经上线。

## 题库与学习批次

`question-bank.json` 是内容源文件，`bank.js` 和 `dist` 都是生成结果，不手工维护。

课程：`system` 为 `cambridge`（默认）、`raz`、`ket`。剑桥 level 1–4；RAZ level 为 D 等字符串。模块支持 lv、rg、skills、reading、vocabulary。题型 choice、cloze、reading、listening，分别检查答案、阅读材料和朗读稿。

真实批次格式：

```json
{
  "id": "ella-YYYYMMDD-book-01",
  "learnedOn": "YYYY-MM-DD",
  "items": [{"lessonId": "已建库课程的稳定编号", "modules": ["reading"]}],
  "note": "首次学习 / 第二轮复读；日期已在对话中确认"
}
```

以上是格式示意，不能原样写入。学习批次中的日期必须确认；未提供日期时不伪造批次，网页以各模块稳定的 `moduleGeneratedOn` 前一天作为默认学习日期。发布时间 `updated` 与生成日期分开，普通部署不得改写模块生成日期。`items` 只引用 ready 状态且已有题目的模块。同日可有多本书、多批内容，同一本书复读新增批次编号。

维护者可以将确认后的单批或数组保存为 JSON 后执行：

```sh
npm run record -- --file /path/to/confirmed-batches.json
npm test
npm run build
```

同编号、同内容重复执行不重复建库。纠正既有日期时确认后加 `--replace`。改变已发布题目的选项、答案或考点时应新建题目编号，以免破坏历史记录。

## 自动复习规则

- 初次学习后 +1、+3、+7、+14、+30 天为检查节点；按时独立答对推进到下一节点。
- 逾期只安排一次当前检查，之后按实际表现重新间隔，不补做所有历史节点。
- 答错或使用提示均重置熟练阶段并安排次日；恢复后从 1、3、7、14、30 天间隔逐步推进。手动家长帮助勾选可在答题前取消，当前选择在暂停、刷新后保留；查看听力文本单独记录，展示明确提示说明，不能通过取消手动勾选消除。
- 同一天重复答对不重复升级；未到期额外练习不推迟已有日期。
- 复读保持已答记录与阶段，可以把较远的下次检查拉近，不代替实际答题。
- 尚未答过的日期纠错可重新计算；已答考点保留表现，不覆盖历史。
- 课程进度只修改首次学习日期，选择后自动保存。RAZ 按整本、剑桥按模块；日期来源内部保留，界面不显示生成日推算过程。本地修改在后续题库发布和备份恢复后仍有效。
- 复读录入入口已移除。旧复读事件仍可读取，题库和学习记录不因界面调整而删除。
- 未来批次等到学习日再启用；页面回到前台/每两分钟检查更新。
- 积压时先跨课程轮换，课程多于题位时优先最近较久未练的课程；同课内优先仍薄弱和逾期的分项。每组可选6/10/15/20题，默认6题，未覆盖内容继续排队；这不是每日硬性题量限制。旧8题设置升级为10题。
- 优先未做过或较少做的变式题；原题库用尽可能重用，增加题量仍通过对话维护。
- 43 道题现分为 23 个复习单元（7 个星期词、3 个活动词组、2 个频率词、8 个听力小组、3 个阅读技能）。每个单元分别计算日期；同组每个单元最多 1 题、每个大考点最多 2 题，内容少时允许短组。
- 旧版综合阶段无法证明每个词都掌握，迁移后分项从阶段 0 重新确认；旧答题历史和累计错误保留。家长「复习记录 → 分项复习」可查每项进度。
- 首次学习日期不能晚于已有复读日期。旧记录中若已有矛盾，按显式首次日期控制启用，较早复读保留但不触发提前启用。

## 记录与更新

浏览器 `lesson-loop-data-v1` 保存作答、熟练度、学习批次处理记录和进行中的练习。保留旧版存储键并向前兼容。

发布新内容会合并稳定编号、自动启用学习批次，不覆盖学习记录。正在练习时推迟题库更新，防止题目中途改变；完成后检查最新内容。备份恢复保留最新已发布题库。

正式 `question-bank.json` 使用 `mode: "snapshot"` 和递增整数 `revision`：快照中删除的题目保留为 `active: false` 的历史题，不再加入新练习。增量导入须声明 `mode: "patch"`，停用题通过 `active: false` 标记。题目选项、答案、正文、题型或所属考点变化必须换新编号；旧题库版本不能覆盖新版本。`reviewUnit` 是考点内的稳定分项编号。手工改内容后递增 revision；`npm run record` 在批次实际变化时自动递增。

所有保存使用 Web Locks 串行化并核对原始记录版本；不支持 Web Locks 时，使用 IndexedDB 的读写事务锁保持跨页面串行化，学习记录本身仍保存在原 localStorage 键。另一个页面已更新时，当前操作中止并读取最新记录，提示重试；不会自动合并两份冲突答案。两种锁都不可用或存储权限被拒绝时，显示错误并停止保存，不静默退化为覆盖写入。

读取异常不会用空状态覆盖原记录，尝试在 `lesson-loop-data-v1-recovery` 留存原文；空间不足时也保留原键。家长端可导出原文；恢复有效完整备份时在 `lesson-loop-data-v1-before-restore` 保存替换前内容，题库版本迁移前在 `lesson-loop-data-v1-before-update` 留存升级前完整记录。写入失败不推进题目，避免把未保存的作答显示成成功。

家长题库显示应用版本、题库版本、构建摘要及当前域名。构建摘要来自源文件内容，便于比较本地包和线上版本；`version.js` 为构建生成文件。

首版不跨设备同步；清除网站数据或换设备前导出完整备份。无可启用内容时的体验题仅保存答题历史。已建库模块按默认或确认日期进入日程，日期可由家长校正。

听力优先播放本站预生成的英式合成女声，支持正常／保调慢速播放和停止；仅音频不可用时使用设备英文备用声音。全部现有听力题及试听稿已配MP3，新增听力题发布前须按 `audio/README.md` 生成音频，构建校验完整性。没有运行时模型API、图片上传服务或自动OCR；内容与音频在维护时生成。

## 验证

`npm test` 覆盖旧版记录兼容、学习日期启用、日历节点、逾期/错题/提示、暂停、日期修正、复读、跨课程混合和新增题目保留历史。浏览器另检查学生入口、即时反馈、学习批次自动登记和网页更新后的记录保留。
